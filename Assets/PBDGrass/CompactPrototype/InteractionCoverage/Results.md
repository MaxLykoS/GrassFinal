# 整个近、中景共享碰撞优先 XPBD 池

Contact Lab 开启 `Physics.InteractionsAcrossMiddle`。注册的球体、胶囊碰撞体在整个兼容草场内都能申请 XPBD，优先于普通近景草；活动预算保持 32768 根。默认中景完整覆盖至 52 米，52～64 米是与无状态外围的过渡带，也允许交互激活。

## 实现

- 使用 `GrassOuterCoverage.CoverageTransition` 的实时中心、边界和径向/方形模式，在模拟和流式选择之前同步；中景范围或相机变化时无需另改 28 米参数。
- CPU 对碰撞体附近做局部空间查询，按草块与覆盖区重叠筛选，再由既有碰撞优先排序分配槽位。每块 32 根，以格中心加 0.71 米半对角线余量判断相交，边界块整块激活；完全在覆盖区之外的碰撞不申请。没有外围表示时，整个驻留草场都可申请。
- 退出与进入沿用原有 GPU 压缩塑性、姿态恢复及 0.4 秒显示交接。CPU 不读取物理结果，没有增加逐叶扫描或正常运行的 GPU 回读。
- 按本次要求没有新增峰值控制，也没有新增物理回弹保留期。碰撞影响区域离开或禁用后，名额按原有规则重新分配；塑性在驻留区域内保留。
- 不扩容物理池、历史池或压缩缓存。历史容量仍为 65536 根，历史主体预留 51 MiB；它不代表同时运行 65536 根 XPBD。多轮交接超过现有硬容量的情况仍沿用原有行为。
- 只在 Contact Lab 显式启用新策略；旧场景的默认值为关闭，保留其原来的交互距离限制。约束、光照、求解器和接受的烘焙数据没有改变。

## 观察方法

打开 `Assets/PBDGrass/Scenes/PBDGrassContactLab.unity` 并 Play，按 `4` 俯视整个范围。09 号叶尖扫动移至 `(-36, 1.55, 14)`，12 号立柱移至 `(38, 0.9, 20)`，它们会在蓝色中景中产生局部绿色 XPBD 区域。按 `C` 移除碰撞体，观察绿色区域释放以及塑性保留。近处绿色区域会让出部分名额。

## 验证

在独立 Unity 2022.3.62f2c1 项目、RTX 3080 Ti 上运行；未访问原工程 `Library/`。离线验证使用的 GPU 回读不属于运行时路径。

- `Tools/PBD Grass/Validate Full Middle Interactions`：510 个完整 tick。40 米和 60 米碰撞、多个独立碰撞区域、近景名额被替换、旧模式保持、碰撞体跨越 64 米边界、纯外围排除、移动后边界更新均通过。全程 32768 根活动 XPBD；交互优先草最多 3552 根。
- 中景碰撞产生的最大塑性弯曲为 0.872665 rad；退出及重叠页移动后压缩塑性逐位保留，重新进入时解码与槽位播种误差为 0。活动节点有限，测试最大根相对距离 2.3352 米。
- 该专项测试的历史实际占用峰值为 65536 根，与预留容量相同；其中包含可丢弃预热记录，不能把此数等同于强制交接需求。没有扩大历史容量。
- 完整 Contact Lab Play：2701 tick、12 个碰撞体、9 次换页、四种视角及塑性 LOD 往返全部通过。活动数量始终为 32768；往返前后塑性峰值约 1.087887 / 1.087910。
- 联合 baseline：1440 tick，32768 XPBD + 98304 贝塞尔；四次进入播种的姿态、线速度、方向、角速度误差为 0，塑性保留误差为 0。八种材料临时重烘焙的节点、控制点、方向、频率、阻尼与接受数据差异全部为 0，原烘焙文件未改变。
- 逻辑 GPU Buffer 分配始终为 **224852832 B = 214.44 MiB**，含外围；这是缓冲分配量，不是总显存或耗时。

专项与完整场景的原始结果以及联合 baseline 回归结果保存在同目录的 `Evidence.zip`；源码指纹见 `Sources.json`。

## 当前耗时记录

独立 Editor、1600×900、12 个碰撞体、分层调试色，预热 120 tick 后采样 300 个完整 tick，使用 GPU 时间戳，丢失/失败采样均为 0。CPU 与 GPU 区间不能相加当作帧时间。

| 区间 | 平均耗时 |
| --- | ---: |
| CPU 模拟池选择 | 0.677 ms |
| CPU LOD 交接管理 | 1.264 ms |
| CPU 完整模拟 tick 准备/提交 | 2.102 ms |
| CPU 记录的总提交区间 | 2.425 ms |
| GPU XPBD 求解＋近景重建 | 2.957 ms |
| GPU 交接阶段 | 0.026 ms |
| GPU 中景/过渡显示更新 | 0.697 ms |
| GPU 记录的总区间 | 4.584 ms |

本轮改变的是交互覆盖与名额分配，没有优化求解器，**32768 根 XPBD 的 1 ms GPU 目标仍未达到**。这些是当前场景实测，不是与旧碰撞体布局严格配对的性能对照。

性能程序完成并保存全部 300 个有效样本后，在 Unity 退出阶段停滞超过 90 秒；核对命令行和项目路径后，仅终止了本轮启动的独立基准进程。记录在 `Evidence.zip` 的 `PerformanceShutdown.json` 中。专项、完整 Play 和联合 baseline 的进程正常退出。
