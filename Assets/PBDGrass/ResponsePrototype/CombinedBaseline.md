# XPBD 与贝塞尔联合优化基准

打开 `Assets/PBDGrass/Scenes/PBDGrassCombinedBaseline.unity`，进入 Play。这是当前优化验收场景；纯 XPBD 的 `PBDGrassDemo.unity` 和 2048 根交接场景继续用于隔离诊断。

| 项目 | 固定配置 |
| --- | --- |
| 草田 | 64 × 64 米，每平方米 32 根，共 131072 根 |
| 近景 | 32768 根 XPBD，1024 个格持续满负载 |
| 外围 | 98304 根贝塞尔程序草；交接期间使用已有显示混合 |
| 材料 | 已接受的第 6 种长、窄、软材料；正常重力、地面、塑性 |
| 物理 | 60 Hz，每 tick 8 个 Small Steps，每子步 3 次约束扫掠 |
| 运行 | 确定性随机风、移动压草球、24 秒自动往返 |
| 相机轨迹 | 横向 ±12 米，近景池随主相机移动 |

候选半径 20 米，按距离选最近的 1024 个格；有效近景边界约 18 米，具体随格子离散和池选择变化。候选数量超过容量是本基准维持满负载的配置，不表示实际多模拟了草。相机轨迹始终留在有限草田内部，外围一圈持续存在。手动走出草田后不保证满负载；那段不能用于 32768 根性能验收。

按键沿用交接演示：`T` 自动/手动，`C` 碰撞，`Space` 风，`G` 随机/固定风，`R` 重置；WASD、右键和 Shift 手动观察。界面同时显示活动 XPBD 和贝塞尔目标数量。Scene 相机仍使用主相机的剔除参数，绘制不推进模拟。

联合场景默认开启 `Handoff / Debug Lod Base Colors`：当前参与 XPBD 的格使用纯绿色 baseColor，其余贝塞尔草使用纯蓝色 baseColor。颜色在模拟归属切换时立即变化，用于观察真实 LOD 边界；几何仍按原流程过渡。只替换 baseColor，法线、高光、透射、环境光、AO、阴影和雾的计算不变，因此屏幕像素仍受光照影响。此开关可以在 Play 中实时关闭，恢复原草色；其他场景默认关闭。下文历史性能样本采集时未开启此颜色调试，性能对照时使用相同开关状态。

## 优化通过条件

1. 完整往返中每个物理 tick 都实际模拟 32768 根。GPU 求解加近景最终几何重建预算仍为 RTX 3080 Ti 上每完整 tick ≤1 ms；贝塞尔更新、交接、剔除、绘制和 CPU 管理分别计时，并报告联合场景总开销。当前全场显示更新也包含近景最终几何，不能全部算给中景而漏掉这部分近景成本。
2. 保留已接受的自然弯曲、卸载回弹和有限塑性倒伏。运行原来的完整物理及塑性交接回归，检查真正淘汰后重入、过渡中反向切换与塑性历史。
3. 使用原有 8 份烘焙表运行八种材料的随机风/快速变风对照。近景求解器变快后，旧表仍要能匹配新的近景运动；文件未修改不代表行为兼容。
4. 用同一份烘焙流程在内存里重新计算 8 种材料的全部 25 个平衡样本和两个方向的动态拟合，比较节点、材料方向、贝塞尔控制点、响应频率和阻尼。测试不覆盖原资产。需要改变物理行为、重新烘焙或迁移数据格式时，明确记录影响，不能悄悄换表来通过回归。

联合场景默认只用第 6 种材料，以保留已经接受的塑性交接效果；8 种材料全部参与烘焙兼容性和独立风响应回归，不代表混合 8 种材料的塑性交接都已验证。

## 可复现检查

菜单 `Tools/PBD Grass/Create Combined 32768 XPBD Baseline` 生成独立场景，不覆盖原场景。`Tools/PBD Grass/Validate Combined 32768 XPBD Baseline` 执行满负载 24 秒往返、状态接续、倒伏历史和 8 种材料的内存重烘焙。较长的同步诊断读回只发生在验证中，正常运行仍不读回模拟状态。

批处理入口分别为 `GrassFinal.PBDGrass.Editor.GrassCombinedBaselineSceneBuilder.Create` 和 `GrassFinal.PBDGrass.Editor.GrassCombinedBaselineValidation.Run`。环境变量 `GRASS_COMBINED_OUTPUT` 指定输出目录。建议在独立验证工程运行，避免影响正在编辑的场景。

还需运行已有 `BakedGrassHandoffValidation.Run`、`GrassResponseValidation.Run` 和 `PlasticGrassValidation.Run`；联合数量检查不能替代这些精细回归。

`CombinedBaselineValidation/` 保存本次验证结果、截图、源文件和烘焙表的 SHA-256。这个快照与历史 baseline 标签分别保留。性能优化尚未开始，旧纯 XPBD 约 2.457 ms 的数据不能当作联合场景实测值。

## 本次功能基准

3080 Ti / D3D11，1440 个固定 tick 全程活动数量最小、最大均为 32768，外围 98304 根。发生 1972 次格子退出和新槽初始化，其中 1082 次为曾经模拟过的格子重新进入。实际倒伏格完成淘汰和返回，远离期间塑性变化为 0。4 次抽查进入格的位置、速度、材料方向和角速度接续误差均为 0；Scene 绘制保持主相机剔除与模拟 tick 不变。

8 种材料各 25 个样本全部在内存中重新计算；节点、控制点、材料方向、两轴响应频率和阻尼与原烘焙数据的差值均为 0。原 8 份资产字节未改动，`AcceptedBakeBank.json` 固定它们的 SHA-256；以后的联合验证先检查这些校验值，再用新求解器重新计算对照。

## 本次 GPU 基准

Unity 2022.3.62f2c1、RTX 3080 Ti、D3D11、1280 × 720。每个阶段预热 120 tick，原生 D3D11 timestamp/disjoint query 非阻塞轮询，环形队列限制最多 32 个未返回帧；无模拟状态同步回读。静止阶段 300 个有效样本，移动阶段覆盖完整 24 秒、1440 个样本，丢弃与失败均为 0。

| GPU 区间，毫秒 | 静止平均 | 往返平均 | 往返 P95 |
| --- | --- | --- | --- |
| XPBD 的 8 次子步 dispatch，含原求解器几何输出 | 2.294 | 2.282 | 2.493 |
| 预计算风、交接显示和全场最终几何 | 1.481 | 1.498 | 1.748 |
| 池选择中的 GPU 捕获/接续提交区间 | 0.009 | 0.027 | — |
| 全场剔除 | 0.007 | 0.008 | — |
| 相机绘制 | 0.548 | 0.489 | — |
| 从模拟开始至相机绘制完成的 GPU 区间 | 4.341 | 4.312 | — |

当前交接路径仍保留求解器自身的几何输出，显示阶段又重建一次最终几何；显示阶段同时处理活动和非活动草。因此 2.282 ms 不是联合路径全部近景成本，1.498 ms 也不是单独贝塞尔草的成本。后续优化必须计入最终显示所需的工作，避免只缩短一段计时、把工作挪到另一段而宣称达标。当前 1 ms 目标尚未达到。

CPU `Advance` 提交耗时平均静止 1.668 ms、移动 1.705 ms，包含选池、上传、驱动调用，不是纯 CPU 算法耗时；未计入相机绘制提交。GPU 总区间包含计时点之间的提交空隙，不等于整个 Unity 编辑器帧耗时或 FPS。其他用户工程保持运行，硬件时钟和竞争会影响绝对值；优化前后应使用相同复现程序和条件。

`GpuResults.json` 保留 1740 条逐样本数据；其中 `passed` 表示采样完整有效，不表示性能预算达标。`GpuReproduction.zip` 包含临时插桩渲染器、驱动程序、原生查询 DLL 与源码，仅用于独立验证工程，正式运行代码没有加入原生插件或同步回读。
